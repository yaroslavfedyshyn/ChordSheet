# App Store submission assets

- `listing.md` — draft App Store Connect copy (name, subtitle, description, keywords, etc.)
- `screenshots/` — App Store screenshots captured from the simulator

The privacy policy and support pages live in [`/docs`](../docs) and are
hosted via GitHub Pages straight from this repo (Settings → Pages →
deploy from `main` / `/docs`):

- `https://yaroslavfedyshyn.github.io/ChordSheet/privacy-policy.html`
- `https://yaroslavfedyshyn.github.io/ChordSheet/support.html`

Paste those into App Store Connect's "Privacy Policy URL" and "Support URL"
fields.
